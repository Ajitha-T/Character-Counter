# Character-Counter
A simple and interactive Character Counter built using HTML, CSS, and JavaScript. This project allows users to type a message in a text area and displays the number of characters entered and the remaining characters allowed in real time.

## Features
- Text area for entering a message.
- Real-time character counting using JavaScript.
- Maximum character limit of 200 characters.
- Displays the number of characters typed and remaining.
- Shows a warning message when the character limit is reached or exceeded.
- Prevents users from entering more than the allowed number of characters.

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
As the user types or edits a message, the character counter updates automatically using the JavaScript `input` event listener. The application tracks the number of characters entered, calculates the remaining characters, and ensures the message stays within the 200-character limit.
